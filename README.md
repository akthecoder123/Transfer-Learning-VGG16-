# 15-Class Fruit Classifier using VGG16 Transfer Learning

This project achieves a **97.29% validation accuracy** classifying 15 different types of fruits by utilizing transfer learning with a pre-trained VGG16 architecture. 

 # Performance
- **Validation Accuracy:** 97.29%
- **Frameworks:** TensorFlow 2.x, Keras
- **Hardware:** Accelerated using dual Tesla T4 GPUs on Kaggle Cloud

#  Dataset Architecture
The project trains on 70,549 images mapped across 15 distinct fruit categories. 
* *Note: The full image dataset is hosted on Kaggle and is not committed to this repository due to storage constraints.*

#  How to Run the Notebook
1. Download the `your-notebook-name.ipynb` file from this repo.
2. Create a new notebook on [Kaggle](https://kaggle.com).
3. Go to File -> Upload Notebook.
4. Run the data loader to pull the live imagery and observe the weights converge!
